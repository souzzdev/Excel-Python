# 📊 Tabela de Gerenciamento no Excel

Este projeto permite **criar e formatar uma tabela de gerenciamento** em um arquivo Excel (.xlsx), com formatação automatizada para CPF, CNPJ, telefone e e-mail, validação de dados e a opção de proteger a planilha com uma senha. 🚀

---

## Funcionalidades ✨

- **Entrada de Dados Personalizada**: O usuário define o nome das colunas e preenche os dados da tabela. 📝
- **Formatação Automática**: O CPF, CNPJ, telefone e e-mail são formatados automaticamente para os padrões corretos. 🔄
- **Validação de E-mails**: Os e-mails inseridos são validados para garantir que estão no formato correto. 📧✅
- **Formatação Visual**: A tabela é formatada com cores diferenciadas para o cabeçalho e as células de dados, além de ajustes automáticos na largura das colunas. 🎨
- **Proteção por Senha**: O usuário pode optar por proteger a planilha com uma senha. 🔐
- **Criação de Tabela no Excel**: A tabela gerada é salva em um arquivo Excel (.xlsx), com todas as formatações e ajustes aplicados. 💾

---

## Tecnologias Utilizadas 🛠️

- **Python 3.x**: Linguagem de programação utilizada para o desenvolvimento do script. 🐍
- **openpyxl**: Biblioteca para leitura e escrita de arquivos Excel (.xlsx). 📊
- **re**: Biblioteca para manipulação de expressões regulares, utilizada para validar e formatar CPF, CNPJ, telefone e e-mail. 🔍
